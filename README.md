# 숲속법정 콘텐츠

앱이 실행될 때 읽어가는 파일이다. `content.json` 하나만 서비스한다.

- 이 저장소는 **공개**여야 한다. 앱이 로그인 없이 읽는다.
- 개인정보를 넣지 않는다. 사연은 각색을 마친 것만 올린다.
- 파일을 덮어쓰면 앱은 다음 실행 때 새 내용을 읽는다. 앱을 다시 올리지 않는다.

## 파일

| 파일 | 무엇 |
|---|---|
| `content.json` | **앱이 읽는 파일.** 아래 두 개로 만들어진다 |
| `rounds.json` | 회차 일정 — 언제 열고 언제 결과를 낼지 |
| `results.json` | 집계와 골라 실은 의견 |

## 평소 순서

앱 작업 폴더(`C:\P_app\soopcourt`)에서:

1. `content/rounds.json` 이나 `content/results.json` 을 고친다
2. `node scripts/build-content.mjs` — 형식을 검사하고 `content.json` 을 만든다
3. 이 저장소에 네 파일을 올린다

검사에 걸리면 파일을 만들지 않는다. **앱은 형식이 어긋난 내용을 조용히 무시하고 기본값으로 돌아가므로**, 잘못 올린 것을 눈치채기 어렵다. 그래서 만들기 전에 막는다.

## 급할 때

날짜 하나만 미루면 되는 경우 `content.json` 의 맨 위 `rounds` 를 GitHub 웹에서 직접 고쳐도 된다. 그 경우 `rounds.json` 도 같이 고쳐 두지 않으면 다음 번에 되돌아간다.
